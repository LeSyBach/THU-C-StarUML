## 🚀 Hướng dẫn cài đặt & Kích hoạt

* **Bước 1:** Tải xuống và cài đặt [StarUML Phiên bản 6](https://staruml.io) từ trang web chính thức.
* **Bước 2:** Tải xuống file `app.asar` đã được tinh chỉnh từ [Google Drive tại đây ☁️](https://drive.google.com/drive/folders/1pKDMpIefGNzWme-GEyVRdk13D6M19Tpf?usp=sharing).
* **Bước 3:** Sao chép file `app.asar` vừa tải ở Bước 2 và chép đè lên file `app.asar` hiện tại của ứng dụng. 

Tùy thuộc vào hệ điều hành của bạn, hãy tìm đến thư mục tương ứng theo bảng dưới đây:

| Hệ điều hành | Đường dẫn thư mục cần chép đè |
| :--- | :--- |
| 🪟 **Windows** | `C:\Program Files\StarUML\resources` |
| 🍎 **MacOS** | `/Applications/StarUML.app/Contents/Resources/` |
| 🐧 **Linux** | `/opt/StartUML/resources` |

* **Bước 4:** Khởi động lại ứng dụng StarUML và tận hưởng thành quả! 🎉
